# Курсова робота з ООП — Варіант №5: Готельний комплекс та бронювання (Hotel Management)

Консольний застосунок на мові **C# (.NET 8.0)** для автоматизації роботи готельного комплексу та бронювання номерів.

## Архітектура рішення
Проєкт розділено на дві частини відповідно до вимог завдання:
1. **`HotelManagement.Core` (Class Library / `.dll`)** — бізнес-логіка, моделі предметної області, узагальнені репозиторії, власні винятки та JSON-серіалізація.
2. **`HotelManagement.UI` (Console App)** — консольний інтерфейс користувача, валідація вводу та обробка винятків.

## Реалізовані компоненти
* **Моделі (`Models/`):**
  * `BaseEntity` — абстрактний базовий клас із унікальним ідентифікатором `Id` (`Guid`).
  * `Room` — готельний номер (`RoomNumber`, `Category`, `Capacity`, `PricePerNight`), реалізує `IComparable<Room>`.
  * `Guest` — гість готелю (`FullName`, `PassportNumber`, `PhoneNumber`).
  * `ExtraService` — додаткова послуга (`Name`, `Price`).
  * `Booking` — бронювання номера на обрані дати з перевіркою тривалості проживання та підрахунком повної вартості (номер + додаткові послуги).
* **Власні винятки (`Exceptions/`):**
  * `DoubleBookingException` — виникає при спробі забронювати номер, зайнятий на обрані дати.
  * `InvalidStayDurationException` — виникає при некоректних датах заїзду/виїзду.
* **Узагальнені колекції та інтерфейси (`Interfaces/`, `Repositories/`, `Comparers/`):**
  * `IRepository<T>` та `Repository<T>` на основі `List<T>`.
  * `RoomPriceComparer` (`IComparer<Room>`) для сортування номерів за ціною.
* **Сервіси (`Services/`):**
  * `HotelService` — управління номерами, гостями, послугами та бронюваннями.
  * `JsonFileService<T>` — автоматичне завантаження та збереження даних у JSON-файли (`System.Text.Json`).
